DingLang 参考手册

一个能写 中文 和 藏文 的小型编程语言，编译到 JavaScript。

概览

# 变量（中文、藏文都行）
let 名字 = "丁子"
let བོད་ཡིག = "藏文"

# 函数
fn 平方(n) = n * n

# if 是表达式，有返回值
let 等级 = if 分数 >= 90 { "优" } else { "及格" }

# 范围循环（藏文数字也能用）
for i in ༡..=༡༠ { པར(i) }

# 字符串插值
པར("{名字} 说：{བོད་ཡིག}")
打字提示：关键字用英文（let fn if）， 但标识符可以是任何文字 —— 中文、藏文、日文、韩文、阿拉伯文都行。

数字 本语言特色

数字字面量支持 Unicode 里的所有十进制数字（属性 \p{Nd}）， 不只是 ASCII 的 0-9。词法分析阶段会统一转成 ASCII， 所以运行时完全等价。

用法

let པ = ༥              # 藏文 ༥ = 5
let 年份 = ༢༠༢༦        # 多位：2026

པར(༥ + ༧)             # 12
པར(༨ * ༢)             # 16
པར(༣.༡༤)              # 3.14（小数也支持）

# 和 ASCII 混着写也行
པར(༡2༣)               # 123
པར(༥ + 5)             # 10

# 范围循环
for i in ༡..=༥ { པར(i) }   # 1 2 3 4 5
注意：数字后面不能直接跟字母。 let x = 1abc 会报错（提示你是不是想写 1 abc）。

反向：把数字输出成藏文数字

པར(藏文数字(2026))      # ༢༠༢༦
པར(བོད་ཨང(2026))       # 同上（藏文别名）
པར(བོད་ཨང(3.14))       # ༣.༡༤

编程里用的是数字符号（༡ ༢ ༣），但藏语口语里读的是数词（གཅིག གཉིས གསུམ）。两者分开：

༢གཉིས༧བདུན
༣གསུམ༨བརྒྱད
༤བཞི༩དགུ

标识符

规则来自 Unicode 标准：首字符必须是 \p{ID_Start}，后续可以是 \p{ID_Continue}。

藏文的特殊情况

藏文用音节点 tsheg（་ U+0F0B）分隔音节， 比如 བོད་ཡིག。 但它在 JavaScript 里不是合法标识符字符，所以本语言额外放行， 在生成代码时替换成下划线。 详见 藏文改名规则。

注释

# 井号到行尾

let x = 42   # 行尾注释也行

语句

let —— 变量

let x = 42
let 名字 = "丁子"
let བོད་ཡིག = "藏文"
let 列表 = [1, 2, 3]

块级作用域，必须给初始值。

fn —— 函数

# 表达式体（自动返回）
fn 平方(n) = n * n

# 块体（需要显式 return）
fn 求和(列表) {
  let 总 = 0
  for x in 列表 { 总 = 总 + x }
  return 总
}

# 匿名函数
let 双倍 = fn(x) = x * 2

if —— 是表达式，有返回值

# 当语句用
if 分数 >= 60 { པར("及格") }

# 当表达式用（可以赋值）
let 等级 = if 分数 >= 90 { "优" }
           else if 分数 >= 60 { "及格" }
           else { "不及格" }

# 一行写法
let 大 = if x > 10 { "大" } else { "小" }

for —— 范围循环 or 遍历

# 范围：含末尾
for i in 1..=10 { པར(i) }

# 范围：不含末尾
for i in 0..10 { པར(i) }        # 0 到 9

# 倒着数
for i in 10..=1 { པར(i) }

# 遍历列表
let 水果 = ["苹果", "香蕉"]
for f in 水果 { པར(f) }

while

let n = 10
while n > 0 {
  པར(n)
  n = n - 1
}

return / break / continue

fn 找第一个偶数(列表) {
  for x in 列表 {
    if x % 2 == 0 { return x }
    if x > 100 { break }
    continue
  }
  return -1
}

藏文改名规则 编译原理

本语言编译到 JavaScript，而 tsheg 音节点在 JS 里不合法，所以必须改名：

DingLang生成的 JavaScript说明
བོད་ཡིགབོད_ཡིགtsheg ་ → 下划线 _
名字名字中文本来就合法，不变
པརཔར没有 tsheg，不变
class_class避开 JS 保留字

冲突检测

因为改名可能撞车，编译器会检查：

let བོད་ཡིག = "第一个"
let བོད_ཡིག = "第二个"     # ← 报错！

# ✗ 第 2 行 第 1 列
#    变量名冲突："བོད་ཡིག"（第 1 行）和 "བོད_ཡིག" 生成 JS 后会撞车
#     原因：藏文音节点 ་ 在生成 JS 时会变成下划线，两者都会变成 "བོད_ཡིག"
#     建议：改成不同的名字
编辑器里点「生成的 JavaScript」标签，能直接看到改名结果。

错误处理

所有错误都带精确的行号和列号，并指出出错位置：

阶段能抓到的错误
词法分析非法字符、字符串没闭合、数字后面跟字母
语法分析括号不匹配、缺表达式、赋值给字面量、缺初始值
语义检查变量名冲突、参数重名、break 不在循环里、return 不在函数里
运行时调用不存在的函数、类型不对

完整语法（EBNF）

程序      := 语句*
语句      := let语句 | fn声明 | for语句 | while语句
           | return语句 | break | continue | 表达式 | 代码块

let语句   := 'let' 名字 '=' 表达式
fn声明    := 'fn' 名字 '(' 参数列表 ')' ('=' 表达式 | 代码块)
for语句   := 'for' 名字 'in' 表达式 代码块
while语句 := 'while' 表达式 代码块
return语句:= 'return' 表达式?
代码块    := '{' 语句* '}'

表达式    := 赋值
赋值      := 逻辑或 ('=' 赋值)?                # 右结合
逻辑或    := 逻辑与 ('||' 逻辑与)*
逻辑与    := 相等 ('&&' 相等)*
相等      := 比较 (('==' | '!=') 比较)*
比较      := 范围 (('<' | '>' | '<=' | '>=') 范围)*
范围      := 加减 (('..' | '..=') 加减)?
加减      := 乘除 (('+' | '-') 乘除)*
乘除      := 一元 (('*' | '/' | '%') 一元)*
一元      := ('!' | '-') 一元 | 后缀
后缀      := 原子 ('(' 参数列表 ')' | '[' 表达式 ']')*
原子      := 数字 | 字符串 | 插值字符串 | 布尔
           | 名字 | '(' 表达式 ')' | 列表 | if表达式 | 匿名函数

数字      := \p{Nd}+ ('.' \p{Nd}+)?      # 任意文字的十进制数字
字符串    := '"' 字符* '"'
插值字符串:= '"' (字符 | '{' 表达式 '}')* '"'
名字      := \p{ID_Start} (\p{ID_Continue} | '་')*
列表      := '[' (表达式 (',' 表达式)*)? ','? ']'

已知限制（v0.1）

限制说明
❌ 没有对象 / 字典只有数字、字符串、布尔、列表
❌ 没有模块系统没有 import，单文件
❌ 没有异常处理没有 try / catch
❌ 没有类型标注动态类型
❌ 没有复合赋值写 x = x + 1，不是 x += 1
❌ 字符串不能跨行用 \n
❌ 范围只能用在 for 里1..=5 不能单独当列表用（可以写 [1,2,3]）
想让它支持什么？ 编译器只有约 1000 行，源码在 src/ 目录，加功能不难。
